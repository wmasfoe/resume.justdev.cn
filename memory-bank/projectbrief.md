# 项目简介

resume.justdev.cn 是一个在线简历制作工具，提供以下核心功能：

## 项目目标

1. 提供简单易用的简历制作界面
2. 支持实时预览和编辑
3. 支持多语言本地化
4. 提供 PDF 导出功能
5. 提供 AI 辅助优化建议

## 核心需求

### 功能需求

1. 简历编辑器
   - 支持实时预览
   - 提供多个模板选项 
   - 支持自定义样式

2. 智能助手
   - 提供写作建议
   - 帮助优化内容
   - 回答用户问题

3. 文件处理
   - PDF 导出
   - 文件上传功能
   - 数据保存和恢复

4. 用户体验
   - 响应式设计
   - 多语言支持
   - 直观的操作界面

### 技术需求

1. 性能优化
   - 快速加载时间
   - 流畅的编辑体验
   - 高效的渲染机制

2. 代码质量
   - TypeScript 类型安全
   - 组件化架构
   - 清晰的项目结构

3. 可维护性
   - 完整的文档
   - 统一的代码风格
   - 模块化设计
